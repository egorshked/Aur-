# VPN-бот (aiogram 3 + aiosqlite)

## Запуск

1. Python 3.10+.
2. Установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate        # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Задайте переменные окружения и запустите:
   ```bash
   export BOT_TOKEN="123456:ABC..."      # токен от @BotFather
   export DB_PATH="./vpn_bot.db"         # необязательно, по умолчанию vpn_bot.db
   python bot.py
   ```
   Windows (PowerShell):
   ```powershell
   $env:BOT_TOKEN="123456:ABC..."; $env:DB_PATH="vpn_bot.db"; python bot.py
   ```

Необязательные переменные: `REMINDER_INTERVAL` (сек, по умолчанию 60), `TZ_OFFSET` (часы, по умолчанию 3 — МСК).

## Что есть

- `/start` — приветствие и кнопки «Мой аккаунт», «Тарифы», «Партнерская программа».
- Мой аккаунт → Мои подписки → текущая подписка или «отсутствует».
- Тарифы → выбор → оплата → выдача ключа (продление складывается с остатком).
- Партнерская программа: ссылка `t.me/<бот>?start=ref_<id>`, 10% с оплат рефералов на бонусный баланс.
- Любой текст вне сценария — подсказка с кнопками меню.
- Напоминания за 3 дня, за 1 день и по окончании подписки. Флаги отправки хранятся в SQLite,
  поэтому после перезапуска бот продолжает с того же места и не дублирует сообщения.

## Перед продакшеном замените заглушки

- `process_payment()` — сейчас любая оплата считается успешной. Подключите Telegram Stars / ЮKassa / CryptoBot.
- `issue_vpn_key()` — сейчас выдаётся демо-ключ. Подключите API вашей панели (Marzban, 3x-ui, Outline).
