# VPN-бот (aiogram 3 + aiosqlite)

## Запуск

1. Нужен Python 3.9 или новее (`python --version`).
2. Положите в одну папку `bot.py`, `requirements.txt`, `.env.example`.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Переименуйте `.env.example` в `.env` и впишите токен от @BotFather:
   ```
   BOT_TOKEN=123456789:ABCdef...
   ```
   (Вместо файла можно задать переменную окружения `BOT_TOKEN`, например в панели хостинга.)
5. Запустите:
   ```bash
   python bot.py
   ```
   В консоли должно появиться `Бот @имя_бота запущен`. После этого напишите боту /start.

Необязательные настройки (в `.env` или окружении): `DB_PATH` (по умолчанию `vpn_bot.db` рядом с bot.py),
`REMINDER_INTERVAL` (сек, по умолчанию 60), `TZ_OFFSET` (часы, по умолчанию 3 — МСК).

## Если не работает

| Что видите | Что делать |
|---|---|
| `ModuleNotFoundError: aiogram` | Не установлены зависимости: `pip install -r requirements.txt` (тем же python, которым запускаете) |
| `Не задан BOT_TOKEN` | Нет файла `.env` рядом с bot.py или в нём нет строки `BOT_TOKEN=...` |
| `Unauthorized` / `неверный формат` | Токен скопирован с ошибкой — возьмите заново в @BotFather |
| `Нет связи с api.telegram.org` | Telegram недоступен с этого компьютера/сервера — нужен VPN/прокси или другой сервер |
| `Conflict: terminated by other getUpdates` | Бот запущен дважды (например, и на ПК, и на хостинге). Оставьте один |
| `SyntaxError` / `TypeError ... unsupported operand type(s) for \|` | Старый Python. Нужен 3.9+ |

## Что есть

- `/start` — приветствие и кнопки «Мой аккаунт», «Тарифы», «Партнерская программа».
- Мой аккаунт → Мои подписки → текущая подписка или «отсутствует».
- Тарифы → выбор → оплата → выдача ключа (продление складывается с остатком).
- Партнерская программа: ссылка `t.me/<бот>?start=ref_<id>`, 10% с оплат рефералов на бонусный баланс.
- Любой текст вне сценария — подсказка с кнопками меню.
- Напоминания за 3 дня, за 1 день и по окончании подписки; флаги хранятся в SQLite, поэтому переживают перезапуск.

## Перед запуском для клиентов замените заглушки

- `process_payment()` — сейчас любая оплата считается успешной.
- `issue_vpn_key()` — сейчас выдаётся демо-ключ. Подключите API вашей панели (Marzban, 3x-ui, Outline).
